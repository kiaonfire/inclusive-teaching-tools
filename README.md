# Good Teaching Tools
Open index.html in a modern browser. No installation or network access required. To publish a prototype, upload index.html to a static host such as GitHub Pages. Each tool has a hash URL (e.g. index.html#estimator).

12 tools: 2 calculators and 10 guided rule-based utilities. The guided tools can copy a tailored prompt for use in an institutionally approved AI service; no AI backend is connected. No data is persisted or transmitted by the app. The text transformations and keyword checks are limited and require human review. Calculator assumptions are illustrative. Keyboard focus, semantic labels and responsive styling are included, but WCAG conformance has not been audited.

Production next steps: validate tool outputs with educators and students; establish approved AI processing and a secure backend; integrate verified institutional guidance; conduct accessibility and privacy reviews. Never place an API key in client-side code.
